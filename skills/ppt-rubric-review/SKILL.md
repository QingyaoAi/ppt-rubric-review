# 手工 PPT 质量门禁与去 AI 味修订（v2.2）

本技能将基于多体裁优秀手工 PPT 与四类典型 Bad AI PPT（文档切页型、精装模板型、卡片炫技空话型、非人引用/防审计注水型）校准出的 **v2.2 双轴评价量表** 落为可执行的质量门禁。**无论从零做 PPT，还是修改/评审已有 PPT，均应按本流程防错、检错、改稿并复评。**

- 完整条目与 0/1/2 锚点：[rubric-v2.2.md](./references/rubric-v2.2.md)（或运行 `python3 scripts/rubric.py guide --genre <01|02|03|04|other>`）
- 命令手册与去 AI 味改稿策略：[review-workflow.md](./references/review-workflow.md)
- 可复用空白 Excel 量表：[手工PPT评价量表_v2.2_模板.xlsx](./references/手工PPT评价量表_v2.2_模板.xlsx)
- 零依赖检查与计分脚本：[rubric.py](./scripts/rubric.py)（仅用 Python 3 标准库，兼容 Claude Code / Antigravity / Codex / DeepSeek）

## 一、制稿前硬约束（做 PPT 时先防住 AI 味）

生成或重构任何 `.pptx` 前，先明确**所属体裁**（`01` 人才与项目汇报 / `02` 科技奖答辩 / `03` 学术报告 / `04` 教学讲授 / `other` 其他），并在构思与出稿阶段严守以下红线：

1. **贯彻核心制作六准则（P1–P6）**：一页只讲一件事（复杂主题拆成连续同题递进页）；优先复用用户/论文/官方已有真实材料并自然标出处；用可核查数字和图示说话；有合适材料时多用高信息密度配图；需要图时先找真实素材，绝不拿无关网图或 AI 失真图冒充实证；图表与正文数字交叉重算，严防幻觉与虚构链接。
2. **绝不触碰 S1–S6 硬核导出工序病**：禁止把整页页眉/边框烘焙成单张满版 PNG 底图；禁止全篇 Blank 且无结构；统一整数级字号阶梯（禁 `11.25/14.25pt` 四分点碎字号）；禁止把完整论证与 `[Sxx]` 引用倾倒进备注而让页面只剩干瘪名词；不用手打错乱页码。
3. **绝不触碰 S7–S10 视觉与内容 AI 味**：
   - 不搞跨页印章式套壳（禁止 ≥60% 页面机械重复固定页底红条，或页页清一色左文右图 / 3–4 列等宽概念卡片 + 廉价线性图标）。
   - 不拿 12+ 行密排大表当版面容器，也不拿 2–3 柱玩具统计图或空心 4 步圆角框冒充领域机制图。
   - 不写中文 0 句号名词碎片、不写“赋能千行百业/数智新生态/全链路闭环”空词排比，也不把同一段 40 字套话跨页复制到多个页面。
   - 严禁泄露任何 AI 流水线元文本（如“被裁掉的要点记在备注里”“TODO/待补充”）。
4. **绝不触碰 S11 非人引用链接与反常出处/口径说明**：
   - **出处按需出现、格式自然**：只对外部数据、原图、引文和公开资源标简洁正式出处（如 `国家统计局 2025 公报`、`[Author et al., SIGIR 2024]`、干净短链如官网/GitHub/数据集主页），**绝不每页机械盖章** `出处：课题组整理 / 内部材料 / 公开资料`。
   - **禁贴机器痕迹链接与检索源码**：绝不在页面正文或嵌入超链接中保留 `?utm_source=chatgpt.com`、`grounding-api-redirect`、超长带参原始链、`[标题](https://...)`、`【1†source】`、`[web:3]` 或编造的占位链接。
   - **禁把内部工作流文件名当正式出处**：绝不在面向观众的页脚写 `来源：XX底表 合并版 / 建议稿 §2 / draft_v3.md / 复算脚本`。
   - **禁写“防审计自证清白”式反常说明**：绝不塞入 `留档可查 / 避免口径争议 / 含时间戳可复核 / 本图仅作示意不代表实际比例` 等真人绝不会放上 PPT 的 AI 免责注脚；需要交代统计口径时用极简人话注明关键范围（如 `n=42, 2025.06`）。
5. **按体裁补齐 H 专项金标准**：
   - `01/02 汇报与答辩`：政策/指南需求锚定与承诺型指标对账（H1）+ 第三方权威背书/红章原件/同行引文（H2）+ 落地前后量化对比与路线/团队/预算保障（H3）。
   - `03 学术报告`：动机与核心方法形式化拆解（H4）+ 实验设置/主结果显著性/消融分析闭环（H5）+ 页内固定位置作者+年份引用（H6）。
   - `04 教学讲授`：问题/现象引入与首尾目标回扣（H7）+ 抽象概念配实例与公式数值代入推演（H8）+ 课堂互动/思考题与大屏可读负荷（H9）。

## 二、出稿后检查与双轴打分（必走闭环）

每完成一版 `.pptx`（或接手评审用户已有 PPT）时，按以下 4 步执行：

### 步骤 1：客观 XML 预检（零依赖，秒级定位硬伤）
```bash
python3 scripts/rubric.py scan /path/to/deck.pptx -o /path/to/review/scan-v1.json
```
读取输出中的 S1–S11 风险预判（含嵌入超链接与正文中的非人链接/内部草稿出处/防审计注脚）、隐藏页、四分点字号、备注/正文比、句号密度、占位符/元文本泄露、跨页照搬套话与推荐抽样页序。

### 步骤 2：渲染并目视检查实际播放画面
- 将 `.pptx` 渲染为图片（如 LibreOffice 转 PDF + `pdftoppm` 转 JPG，或使用当前环境可用的演示渲染工具），**亲眼查看导出画面**，不能只看 XML 或源码文字。
- **≤35 页**：全页详评（`--mode full`）；**>35 页**：全稿缩略图通览 + 分层抽检 10–12 页（`--mode sample`，覆盖封面、目录/导航、章节页、核心机制/架构页、数据/表格页、一手实证/案例页、连续展开页、收口页）。
- 重点目视核查：文字重叠/截断/生硬断词、图内小字（<10pt）、图表与正文数值一致性、图片与主题是否张冠李戴、跨页构图是否模板盖章、导航页是否真正标出当前章节、页脚链接与出处说明是否像真人所写。

### 步骤 3：填写带证据的 v2.2 评审记录
```bash
python3 scripts/rubric.py init \
  --deck "draft-v1.pptx" --genre <01|02|03|04|other> \
  --pages <N> --total-slides <TOTAL> --mode <full|sample> --target 88 \
  -o /path/to/review/round-01.json
```
逐项填入 `vetoes`（V1–V4）、`signals`（S1–S11）、`overall`（13 通用 + 3 启用 H 项）和 `pages`（10 项单页判据：`A3, C1, C2, C4, D1, D2, E3, F1, F2, F3`）。每一项须给可定位的页码与画面证据，不凭印象给分。

### 步骤 4：计分并生成修改队列
```bash
python3 scripts/rubric.py score /path/to/review/round-01.json -o /path/to/review/score-01.json
```
核对输出中的**整体得分**、**去 AI 味指数**、**A–H 八维分**、**档位（S/A/B/C/D）**、**是否达标**与自动排序的 `fix_queue`。

## 三、循环修订与复评（何时停手）

仅要求“评审”时，直接交付评分报告与可定位修改清单；凡涉及**制作或修改 PPT**，按以下闭环迭代直至达标：

1. **严格按优先级改稿**（具体改法见 [review-workflow.md](./references/review-workflow.md)）：
   - **P0 否决阻断（V1–V4）**：先修数值冲突、虚构链接、错图、缺失核心交付、泄露元文本/检索源码与重度导出工序病。
   - **P1 红灯指纹（S1–S11 = 2）**：逐一清零工序红灯与跨页套壳/缺真素材/卡片空话/复读/非人引用红灯。
   - **P2–P3 所有 0 分项**：清零全部整稿 0 分与超限的单页 0 分。
   - **P4–P5 去 AI 味核心短板（★）与高权 1 分项**：优先补定制机制图（F2）、一手真实素材（F1）、自然表达（D2）、构图多样（E2）、来源自然可核（F4）、导航高亮与收束（B3）及体裁专项（H）。
2. **禁止凭空造假**：缺少真实一手截图、照片、案例数据或权威来源时，保留明确待补标注并向用户索取材料，绝不编造数字、虚构链接或找无关网图冒充。
3. **重渲染 + 复评 + 轮次对比**：
   - 在可编辑 `.pptx` 副本上修改并保存新版本（如 `draft-v2.pptx`），重新运行 `scan` 并**重新渲染改动页及受影响相邻页**目视验收。
   - 保存新轮次记录 `round-02.json`，运行 `score` 与 `diff`：
     ```bash
     python3 scripts/rubric.py diff /path/to/review/round-01.json /path/to/review/round-02.json
     ```
4. **交付停手条件**：达到 **S 级（整体 ≥88、去 AI 味 ≥85、V1–V4 全通过、S1–S11 红灯=0、整稿 0 分=0、含 0 分页 ≤10%）** 或满足用户指定目标分，且最终版本已做全稿复检无新破版。若因外部素材缺失无法彻底达标，如实交付当前最佳版本、轮次分数对比与明确的待补素材清单。

## 四、反误杀边界（避免机械教条扣分）

- **同题多页连续递进**（如问题→机制→实验或同矩阵逐页高亮）是优秀手工常态，在 B2/E2 应给高分而非扣分。
- **全稿无备注**（现场口述型手工稿）：`D4` 允许标 `"不适用"` 并写明理由，不扣分。
- **纯数学推导/概念教学页无照片**：`F1` 可标 `"不适用"`，或以真实数据集/原生公式+可核算数值算例计高分。
- **正常的短资源链接**（课程主页、开源 GitHub 仓库、公开数据集/评测入口、论文主页）：完全合规，**不触发** S11。
- **零星人工小糙**（封面个别日期待填、个别证书墙偏密、配音图标轻触边）：仅在 `G2`/`C4` 扣分，**不触发** V2/V3 否决阻断。
