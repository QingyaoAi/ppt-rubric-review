# 手工 PPT 评价量表 v2.3 完整判据与锚点

面向项目与人才汇报、科技奖答辩、学术报告、教学讲授的通用双轴评价量表，覆盖五类典型 AI 味范式（文档切页型、精装模板型、卡片炫技空话型、非人引用链接/防审计注水型、**语言生硬/生造黑话与过度压缩腔**）。

- **双轴评定**：同时计算「整体手工水平分（0–100，满权 100）」与「去 AI 味指数（0–100，11 项核心池满权 41）」。
- **实评结构**：4 条否决项（V1–V4）+ 12 条 AI 味指纹（S1–S12）+ 23 条通用核心（13 整稿 + 10 逐页 = 88 权）+ 3 条随体裁自动启用的 H 专项（12 权）= **26 实评项 / 100 权**。

## 一、交付底线否决项（V1–V4，命中任一即判 D 级阻断）

| ID | 否决项 | 触发条件（确认即「阻断」） | 不误杀边界 |
|---|---|---|---|
| **V1** | 重大事实错误、虚构链接或证据张冠李戴 | 确认关键事实/数字造假或幻觉、编造不存在的引用链接/DOI、页内/跨页核心数值严重冲突（如图表占比 68% 冲突正文 62%），或拿无关图片/网图冒充本项目实证。 | 关键主张缺外部核实材料时留空待核，不臆测判阻断。 |
| **V2** | 关键内容严重不可读或损坏 | 最终播放/导出画面中，核心页或多页必读文字、数据、公式、关键图示被严重遮挡、裁切、越界、糊至无法辨认，或媒体损坏。 | 个别证书墙偏密或配音图标轻触边沿只扣 C4，不触发 V2。 |
| **V3** | 核心交付任务未兑现、大面积占位或泄露 AI 元文本/源码 | 缺必交核心章节/关键页（如建设方案无目标无路径），多处实质占位未填，或泄露 AI 流水线元文本、搜索角标/Markdown 链接源码（如“被裁掉的要点记在备注里”、`[标题](https://...)`、`【1†source】`）。 | 封面个别日期/编号待填只扣 G2，不触发 V3。 |
| **V4** | 重度 AI 粗制工序或大面积机械注水 | ① S1–S6 硬核导出工序红灯同时命中 ≥2 项；或 ② 全稿大面积机械复制注水（多页照搬同一套话/同页重复粘贴）且缺真实素材。 | 复合触发，优秀手工零误杀。 |

## 二、AI 味与工序风险指纹（S1–S12，0 无 / 1 轻度 / 2 显著红灯）

| ID | 分组 | 风险信号 | 红灯（=2）触发基准 |
|---|---|---|---|
| **S1** | 工序 | 满版烘焙底图替代母版 | ≥50% 页复用同一不可编辑满版底图（把页眉/边框烘焙死）且正文缺真实图 |
| **S2** | 工序 | 全篇 Blank 且无占位符骨架 | Blank/空白 ≥80% **且**标题占位符 ≤10% 且无正常内容版式（复合条件防误杀） |
| **S3** | 工序 | CSS 四分点字号或字号碎档 | 四分点字号（×.25/×.75pt）≥30% 或相邻 <1pt 碎档泛滥 |
| **S4** | 工序 | 文档倾倒进备注 | 备注/正文字数比 ≥5× 且完整句子全倒进备注、页面只剩干瘪名词碎片 |
| **S5** | 工序 | 手打页码与页序错乱 | ≥30% 页为手打纯数字页码且过半与实际放映页序不符 |
| **S6** | 工序 | 引用/出处仅藏备注 | 大量引用编号（如 `[Sxx]`）仅在备注出现，页面仅剩无法定位的泛化标签 |
| **S7** | AI味 | 跨页机械套壳（模板印章） | 大半正文页机械套用固定卡片/左文右图/大表，或 ≥60% 页机械重复固定底红条 |
| **S8** | AI味 | 真实领域素材匮乏 | 几乎无一手真实素材或定制机制图，大量用大表（≥25%页占≥25%）或玩具柱图填版面 |
| **S9** | AI味 | 卡片/图标/炫技空话味 | 满屏 3–4 列等宽概念卡片 + 廉价线性图标（火箭/灯泡/齿轮）/炫技渐变/AI 概念图 + 四字空词排比 |
| **S10** | AI味 | 机械复读与生成穿帮 | 多页逐字照搬同一口径套话、同页重复粘贴条目、正文与底条大段复读或泄露元文本 |
| **S11** | AI味 | 非人引用链接与反常出处/口径说明 | 出现含 `utm_`/AI 跳转参数的生链或 Markdown/搜索角标源码泄露（`[文](url)`、`【1†source】`）；拿内部底表/草稿/合并版/本地文件名当正式出处；多页机械盖章“课题组整理/内部材料/公开资料”伪出处；或反复出现“留档可查/避免口径争议/仅作示意”等防审计式免责注脚 |
| **S12** | AI味 | **语言生硬、生造黑话与过度压缩腔** | 多页频繁出现读不懂的 AI 生造词（如“国际竞合窗口/固化领跑势能/前置化解/现成制度接口”）、自造四字硬缩词（如“跨模融通/算网智融”）、互联网/汇报黑话堆砌（“压实硬任务/基座底座/抓手/底盘/颗粒度”），或大段长定语绕口句导致听众必须停顿猜意思 |

## 四、体裁专项模块（H 维，9 项预置自动启用 3 项 = 12 权）

- **`01 人才与项目汇报` / `02 科技奖答辩`**：
  - **H1（4 权）** 需求/政策锚定与承诺型指标对账（对比基线、立项/中期/完成目标）
  - **H2（4 权）** 第三方权威背书与代表性成果评价（专家头像引文、红章鉴定、获奖/排名）
  - **H3（4 权）** 落地成效对比与实施保障（真实单位前后量化对比、技术路线/团队/经费）
- **`03 学术报告`**：
  - **H4（4 权）** 研究问题动机与核心方法形式化拆解
  - **H5（4 权）** 实验验证完备性（设置/基线 → 主结果显著性 → 消融/效率/案例分析）
  - **H6（4 权）** 学术引用规范与文献可追溯性（页内固定位置标注作者+年/顶会或简洁项目主页链）
- **`04 教学讲授`**：
  - **H7（4 权）** 问题/现象/实物引入与首尾目标回扣闭环
  - **H8（4 权）** 抽象概念配例证与公式数值代入/可核算推演
  - **H9（4 权）** 教学互动设计、思考/练习题与课堂投屏友好度
- **`other 其他`**：H1–H9 全部自动不适用，系统按通用 88 权折算回 100 分。

## 五、四档综合判定与核心准则（P1–P7）

| 档位 | 整体得分 | 去 AI 味指数 | 硬性约束 |
|---|---:|---:|---|
| **S 级｜优秀手工标杆** | ≥ 88 | ≥ 85 | V1–V4 全通过；S1–S12 红灯=0；整稿 0 分=0；含 0 分页 ≤10%（≤5 页要求 0 页） |
| **A 级｜良好手工级** | ≥ 75 | ≥ 72 | V1–V4 全通过；工序红灯 S1–S6=0；AI 味红灯 S7–S12≤1 |
| **B 级｜混合·短板/AI味** | ≥ 55 | ≥ 40 | V1–V4 通过但未达 A 级 |
| **C 级｜明显 AI 味/重做** | < 55 | 或 < 40 | 未触否决但综合或去 AI 味严重不达标 |
| **D 级｜阻断交付** | 任意 | 任意 | V1–V4 任一项判「阻断」 |

**核心制作准则（P1–P7，已融入上述条目）**：
1. **P1 一页只讲一件事**（`C1, B2, C3`）— 复杂主题拆为连续同题递进页，不硬塞。
2. **P2 优先复用已有合适材料**（`F1, F4, H2`）— 复用论文原图、系统界面、官方证书并自然留出处。
3. **P3 用数字和图说话，不只靠文字**（`A2, A3, F1, F2, F3, H8`）— 明口径基线、定制机制图、数值代入。
4. **P4 有合适材料时多用有效配图**（`F1, F2, C2, S8, S9`）— 真图与机制图取代文字墙和大表，拒装饰图标。
5. **P5 需要图时先查找真实素材，不直接生成**（`F1, F4, V1, S9`）— 严禁拿无关网图或 AI 失真图冒充实证。
6. **P6 反复核查幻觉与非人引用**（`A2, A3, F4, H6, V1, S11`）— 交叉重算图表与文字数字，引文与链接真实自然、零追踪生链与防审计废话。
7. **P7 语言通顺自然，杜绝生造黑话与硬缩词**（`D2, D3, S12`）— 写完必须逐句默读过关，消灭“国际竞合窗口/领跑势能/跨模融通/算网智融”等脱离领域共识的生硬造词和绕口长定语。
