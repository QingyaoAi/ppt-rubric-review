# CLI 命令、复评记录格式与去 AI 味改稿手册（v2.2）

所有命令位于本技能目录的 `scripts/rubric.py`，**仅使用 Python 3 标准库（零第三方依赖）**，在 Claude Code、Antigravity、Codex、DeepSeek 环境中均可直接运行。

---

## 一、常用 CLI 命令

假设技能目录为 `<SKILL_DIR>`（例如 `~/.claude/skills/ppt-rubric-review`），当前任务目录为 `<WORK>`：

```bash
# 1. 查看指定体裁的完整 v2.2 锚点（01/02/03/04/other）
python3 <SKILL_DIR>/scripts/rubric.py guide --genre 01

# 2. 对 .pptx 做零依赖 XML 客观预检（检出 S1-S11 线索、嵌入超链接、占位符与复读）
python3 <SKILL_DIR>/scripts/rubric.py scan <WORK>/draft-v1.pptx -o <WORK>/review/scan-v1.json

# 3. 初始化第 1 轮评审记录（<=35 页用 full 全评；>35 页可用 sample 抽检 10-12 页）
python3 <SKILL_DIR>/scripts/rubric.py init \
  --deck "draft-v1.pptx" --genre 01 --pages 32 --mode full --target 88 \
  -o <WORK>/review/round-01.json

# 长稿抽检示例（例如 90 页稿抽 12 页）
python3 <SKILL_DIR>/scripts/rubric.py init \
  --deck "long-talk.pptx" --genre 03 --pages 12 --total-slides 90 --mode sample \
  --slide-numbers 1,2,10,18,28,40,52,64,74,82,89,90 --target 88 \
  -o <WORK>/review/round-01.json

# 4. 校验、计算双轴得分与档位，并输出按优先级排序的修改队列
python3 <SKILL_DIR>/scripts/rubric.py score <WORK>/review/round-01.json -o <WORK>/review/score-01.json

# 5. 修订并复评后，对比两轮变化（总分/去AI味/红灯/逐项Δ）
python3 <SKILL_DIR>/scripts/rubric.py diff <WORK>/review/round-01.json <WORK>/review/round-02.json
```

## 二、JSON 评审记录填写规范

- `vetoes.V1..V4`：`status` 填 `"通过"` 或 `"阻断"`（缺外部材料待核留 `null`）；`evidence` 必填页码或检查范围。
- `signals.S1..S11`：`level` 填 `0` / `1` / `2`；凡填 `1` 或 `2` 时 `evidence` 必填具体页码与事实。
- `overall.<ID>`：`score` 填 `0` / `1` / `2`（仅允许不适用项如无备注 `D4`、纯原创无外部引用 `F4`、单页稿 `B2/E2` 可填 `"不适用"`）；`evidence` 必填定位与理由。
- `pages[]`：
  - `role`：一句话写清本页讲述任务（如 `p15 核心机制：系统架构与关键模块对比`）。
  - `items.<ID>`：10 项单页分（`A3, C1, C2, C4, D1, D2, E3, F1, F2, F3`），仅 `A3/F1/F2/F3` 可填 `"不适用"`；高分写明具体观察到的元素，低分写清 `问题 + 改法`。
- `changes`：记录本轮执行的具体修订与页码变更映射，便于跨轮追踪。

## 三、四类 Bad AI 味专项修改手册

按 `score` 输出的 `fix_queue` 顺序（**P0 否决 → P1 红灯 → P2 整稿 0 分 → P3 单页 0 分 → P4 去 AI 味短板 → P5 高权提分项**）执行修改：

### 1. 根治「文档切页型 AI 味」（命中 S1–S6 / V4）
- **去掉烘焙底图（S1）**：删掉反复铺满整页的 PNG 壳图，改用原生母版/版式背景与浅色矢量页眉页脚。
- **恢复结构与字号阶梯（S2/S3/G1）**：建立明确整数级字号阶梯（标题 24–32pt、小标题 16–20pt、正文 14–16pt、脚注 10–12pt），消灭 `11.25pt / 14.25pt` 四分点碎字号。
- **反转备注倾倒（S4/D2/D4）**：把核心结论与关键论证提炼回幻灯片正文（自然观点句，避免 0 句号名词碎词），备注瘦身为口播提示或时间码。
- **修复页码与页内出处（S5/S6/F4）**：手打错乱页码换为原生页码域或统一删除；把藏在备注里的 `[Sxx]` 引用还原为页面底部的“作者+年份/权威机构”。
- **拆分巨型大表（S8/F3）**：12 行以上无重点大表绝不直接铺满整页——提炼为 4–6 行对比摘要表 + 高亮最优值 + 旁配机制图或结论句。

### 2. 根治「精装模板型 AI 味」（命中 V1/V3/S7/S8/S10）
- **交叉验算反幻觉（V1/A3）**：每张图表的数据必须与同页文字、跨页汇总逐一重算；凡涉及项目实景、系统界面、试点案例，必须用真实一手素材，缺素材时向用户索取或留明确待补位，**绝不拿无关公开网图顶替**。
- **清除流水线穿帮与复读（V3/S10/D3）**：全局删除任何“被裁掉的要点记在备注”等元文本；严禁在多页表格下方粘贴同一段 40 字套话；标题、正文、结论条各司其职，不车轱辘复述。
- **打破跨页模板盖章（S7/E2/C3）**：取消在 ≥60% 页面固定坐标硬盖同款页底红条/结论条的做法（仅在真正需要收束的关键页使用）；相邻页构图按内容切换（架构图 / 对比矩阵 / 真实案例图文 / 数据表 / 留白断言页交替出现）。
- **替换玩具柱图与空心词框（S8/F1/F2）**：删除为凑图硬塞的 2–3 柱简单统计图和通用 `01→02→03→04` 空心圆角框，改为领域定制机制图、真实系统/论文/证书截图或可核算推导示例。

### 3. 根治「卡片炫技空话型 AI 味」（命中 S9/D2/E1）
- **拆除等宽概念卡片阵（S9/C2）**：不要把每页都做成 3 列或 4 列等宽圆角卡片 + 顶部通用线性图标（火箭/齿轮/灯泡/握手）；用真实层次（左总右分、流程因果、数据对比、案例实景）决定版面。
- **清除炫技特效与 AI 概念废图（E1/F1）**：去掉深色霓虹渐变、重投影、发光描边和无信息的“赛博大脑/科技光束”生成图，回到近白/干净浅底 + 1–2 个节制语义主色。
- **删空词、落颗粒度（D2/A2）**：逐句清理“赋能千行百业、构建数智新生态、全链路闭环”等宏大空话，替换为“具体对象 + 动作 + 量化结果/前后对比/真实个案”。

### 4. 根治「非人引用链接与反常出处/口径说明」（命中 S11/F4/V1/V3）
- **清理追踪长链与检索源码（S11/V3）**：彻底删掉带 `?utm_source=chatgpt.com`、`grounding-api-redirect`、`__biz=`、95+ 字查询串的原始生链（同时检查 `.pptx` 嵌入超链接目标！），以及残留的 `[标题](https://...)`、`【1†source】`、`[web:3]`、`turn0search` 等源码痕迹。确需给观众提供入口时，只保留干净短链（如官网主页、GitHub 仓库、arXiv/公开数据集短链）。
- **删除内部工作流/草稿文件名出处（S11/F4）**：把 `来源：XX底表 合并版`、`来源：建议稿 §2.1`、`来源：draft_v3.md`、`出处：课题组内部整理/公开资料整理` 改为面向外部观众的正式出处（例如 `来源：国家统计局 2025 公报`、`[Author et al., SIGIR 2024]`）；若本页是团队自身方法或总结且无需外部引证，**直接不加伪出处标签**，绝不每页机械盖章。
- **删除“防审计/自证清白”式反常注脚（S11/D2）**：删掉 `口径：指标定义与验收材料一并归档…留档可查`、`调研记录含时间戳，可复核`、`避免口径争议`、`本图根据公开资料整理绘制，仅作示意` 等真人绝不会放上 PPT 的 AI 自我辩护话术。真正需要说明统计口径时，用简短人话交代关键参数即可（如 `n=42 份实测样本，2025 年 6 月`）。
- **严查虚构链接（V1）**：任何放到幻灯片上的 URL/DOI/论文标题必须真实可核，不靠记忆拼接链接。

## 四、可视化复核与重渲染

- 修改完 `.pptx` 后，必须重新渲染受修改页与相邻页（如通过 LibreOffice `soffice --headless --convert-to pdf` + `pdftoppm -jpeg` 或 PowerPoint/Keynote 导出图片）并**亲眼检查导出画面**，确认无文字溢出、无断词错行、无元素重叠遮挡、无表格文字过小（<10pt）。
- 若环境无法执行自动渲染，明确标注视觉渲染待人工复核项，不伪造已目视检查通过的证据。
- 如需交付离线审阅表，可直接复制本技能目录 `references/手工PPT评价量表_v2.2_模板.xlsx` 填写。
